# 청약딱 — 내 조건 맞춤 청약 필터

**▶ https://sis00337.github.io/cheongyak-ddak/**

청약홈(applyhome.co.kr)의 전국 공고를 **무주택·유주택 여부, 거주지, 청약통장 예치금**만 넣으면
"지금 신청 가능한 공고"와 "안 되는 이유"로 갈라서 보여주는 정적 웹앱입니다.

- 데이터 기준일: **2026-11-25** — 접수중·접수예정 공고 **38건 / 전국 12개 시도**
- 서버·DB·외부 라이브러리 없음. `index.html` + `styles.css` + `app.js` + `data/listings.json` 네 파일이 전부입니다.

## 되는 것

| 기능 | 설명 |
|---|---|
| 내 조건 3초 입력 | 주택 수 / 거주지(8개 광역권) / 예치금 / 세대주 여부 → 브라우저 `localStorage`에만 저장 |
| 전국 필터 | 시도 단위 판정, 광역권 칩으로 선택 |
| 스마트 필터 | 지원 가능·조건 미달·관심·전체, 마감 임박·발표일·분양가·물량·지역 정렬 |
| 불가 사유 배지 | `예치금 50만 원 부족 (300만 원 필요)` 처럼 이유를 그대로 표시 |
| 당첨자 발표일 중복 | 관심 공고의 발표일이 겹치면 경고 (1인 1건 규칙) |
| 상세 드로어 | 공고문 원문 근거 인용, 일정 타임라인, 주택형별 공급 금액, 문의처, 공고문 PDF 링크 |
| 원문 미확인 표시 | 자격을 확인하지 못한 공고는 추정으로 통과시키지 않고 `원문 미확인`으로 표시 |

## 데이터

- 출처: 청약홈 입주자모집공고 (APT 분양정보 / APT 잔여세대 / 오피스텔·민간임대)
- 자격 판정은 공고문 '신청자격' 문구를 규칙으로 옮긴 것이며, 근거 문장을 `evidence` 필드에 남깁니다.
- 예치금은 「주택공급에 관한 규칙」 85㎡ 이하 1순위 기준을 시도별로 계산합니다
  (서울·부산 300만 / 인천·대구·광주·대전·울산 250만 / 그 밖의 지역 200만 원).

`data/listings.json` 구조(`금액 단위: 만 원`):

```jsonc
{
  "meta": { "source": "...", "collectedAt": "2026-11-25", "count": 38 },
  "listings": [
    {
      "id": "ah2026000576",
      "name": "아르뮤제자이",
      "region": "경기",                       // 시도
      "regionGroup": "경기",                  // 앱의 광역권
      "supplyType": "민영 1순위",              // 민영 1순위 | 공공분양 | 무순위 | 임의공급 | ...
      "housingRequirement": "1주택 가능",      // 무주택 전용 | 1주택 가능 | 무관 | 확인 필요
      "requiredDeposit": 200,
      "residenceRequirement": "수도권",        // 전국 | 수도권 | 해당지역 | 확인 필요
      "eligibleRegions": ["서울", "경기", "인천"],
      "priceMin": 109900, "priceMax": 140840,
      "applyStart": "2026-11-23", "applyEnd": "2026-11-25",
      "announceDate": "2026-11-12",
      "verified": true,
      "evidence": { "housing": "…", "residence": "…" }
    }
  ]
}
```

## 갱신 방법

`data/listings.json` 한 파일만 갈아끼우고 커밋하면 GitHub Pages가 몇 분 안에 새로 배포합니다.
수집 스크립트는 로컬 작업 폴더(`cheongyak-filter-app/scripts/sync_applyhome.py`)에서 돌립니다.

```bash
python3 scripts/sync_applyhome.py          # 오늘 기준 활성 공고 → data/listings.json
python3 scripts/sync_applyhome.py --review # 판정 근거를 사람이 읽는 표로 출력
```

## 주의

- 정보 제공용이며 청약 대행이 아닙니다. 최종 자격은 공고문 원문으로 확인하세요.
- 공공분양·민간임대는 소득·자산 기준이 함께 있습니다. 이 앱은 소득·자산을 입력받지 않으므로
  통과 판정이 곧 자격 충족은 아닙니다.
- 입력한 조건은 브라우저에만 저장되고 어디로도 전송되지 않습니다.
